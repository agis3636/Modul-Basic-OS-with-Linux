## Raspberry Pi bisa digunakan untuk apa?

| Penggunaan       | Contoh nyata                                            |
| ---------------- | ------------------------------------------------------- |
| Server mini      | Web server, DNS server, VPN, file server                |
| Belajar jaringan | Praktik DHCP, DNS, monitoring jaringan, dan Linux       |
| IoT / Smart Home | Mengontrol lampu, sensor suhu, pintu otomatis           |
| Belajar coding   | Python, Java, C/C++, dan otomasi                        |
| Media center     | Memutar film dan media di TV                            |
| Retro gaming     | Emulator game konsol lama                               |
| Monitoring       | Memantau suhu, kamera, perangkat, atau kondisi jaringan |
| Robotika         | Mengendalikan motor, sensor, dan robot melalui GPIO     |

## Contoh buat lab IT lu

Raspberry Pi bisa dijadikan server kecil yang menyala 24 jam untuk:

- DNS lokal, misalnya `kasir.local` dan `sekolah.local`.
- Monitoring jaringan kantor.
- Pi-hole untuk memfilter domain iklan.
- VPN agar bisa mengakses jaringan kantor dari luar.
- Home Assistant untuk otomasi perangkat.

## Bedanya dengan PC biasa

| Raspberry Pi                                   | PC / server biasa                                                |
| ---------------------------------------------- | ---------------------------------------------------------------- |
| Kecil dan hemat listrik                        | Umumnya lebih bertenaga                                          |
| Menggunakan prosesor ARM pada kebanyakan model | Umumnya Intel/AMD x86-64                                         |
| GPIO tersedia untuk proyek elektronik          | Biasanya perlu perangkat tambahan                                |
| Cocok untuk layanan ringan dan IoT             | Lebih cocok untuk VM banyak, database besar, AI, dan beban berat |

Kesimpulan: Raspberry Pi cocok untuk belajar Linux, jaringan, server kecil, dan IoT tanpa harus menyediakan PC penuh. Namun, kompatibilitas aplikasi dan distro harus sesuai dengan arsitektur ARM serta model Raspberry Pi yang digunakan.
